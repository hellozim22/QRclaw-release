## Decisions
- BYTEA encoding for Supabase PostgREST: `\\x` hex prefix format
- Conversation ID resolution via two-step lookup: qrCodeId+sessionToken (specific) then qrCodeId only (fallback)
- DEK cache + DB key_id cache separation to handle in-memory vs persistent state
- Persist is best-effort non-blocking (`.catch()`) — message delivery not blocked by DB write failures
- Stream messages: chunks buffered in memory, concatenated on `stream_end`, then persisted as single message
