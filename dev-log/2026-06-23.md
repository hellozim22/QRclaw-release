# 2026-06-23 — 本地 v1 项目精简（ECC orchestrate: refactor）

## 意图

按用户要求做减法：本地单用户、无邮箱登录；保留 Chat + Agents + 个人资料；极致体验：
1. 打开项目自动识别本机 Agent，否则引导安装
2. 每个 Agent 可对话且响应快

## 实施（Phase A–E）

### Auth / 启动
- `scripts/seed-local-owner.mjs` — 固定 `local-dev@localhost` 用户
- `setup-local-env.sh` — 写入 `NEXT_PUBLIC_LOCAL_DEV=1` + bootstrap 凭据
- `POST /api/dev/bootstrap` + `LocalDevBootstrap` — 无 `/login` 进 Chat
- `dev-up.sh` — seed → 解析 user_id → auto attach host

### Web 裁减
- `middleware.ts` — `/` → `/chat`；legacy 路由 redirect；本地不强制 login
- `settings/page.tsx` — 头像上传 + 名称；移除退出登录
- `page.tsx` — LOCAL_DEV redirect `/chat`

### Gateway
- `server.ts` — unmount messages/subscribe/qrcode/agent-conversations
- `local-host/status` — 增加 `providers[]`、`install_hint`

### UX
- Chat 轮询：Host offline 5s / online 15s
- 连接横幅文案简化 → `bash scripts/dev-up.sh`

## 体验优化（Multica 对齐，Wave 0–5）

### 实施
- Progress 增加 Project 模型、owner 命名空间 localStorage、Project 筛选/新建、卡片 Project + Agent 归因。
- Task 详情改为单行标题 blur 保存、Assignee/Project 下拉可改、Details 单区编辑/阅读切换、Activity 头像 timeline 与 Live 执行条。
- Chat 发消息后显示「已加入 Progress」toast，并避免阻挡 composer。
- Runtimes 从侧栏移除，`/runtimes` 兼容跳转到 `/agents`；Agents 页面不再展示「本机运行状态」模块，仅通过 Agent 列表绿点表达在线状态。
- `/agents` 重构为左列表 + 单一配置详情；去掉 Instructions / Connection tabs，并把「工作方式/描述」合并成一个类似 `CLAUDE.md` 的「角色说明」字段。
- Progress 看板去掉占位空栏；Details 编辑态增加明确「保存」按钮。
- Chat 历史修复：非当前 Agent 的预加载消息不再被丢弃；已加载历史会自动恢复为 drawer 中的「历史会话」。
- 回复速度链路优化：前端请求 Gateway 前不再额外调用 `supabase.auth.getUser()`，直接使用本地 session token，由 Gateway 负责 JWT 校验。
- 新增 ECC 脚本：Projects / Runtimes / Agents；更新主脚本与 3-agents 脚本。
