# 2026-06-25 — QRClaw macOS Loop 10 可交付收尾

## 目标

路线 A 可交付：双击 QRClaw.app → WKWebView 内 Chat 可用，无邀请码，bundled runtime 独占端口，DMG 可安装。

## 改动摘要

### macOS Orchestrator

- `claimExclusivePorts()` — 启动前清 :3000/:3100/:19515，避免复用 next dev / dev-up 残留
- `isOurBundleGateway()` / `isOurBundleWeb()` — 仅复用带 `qrclawBundle` marker 的 bundled 服务
- `DesktopPublicConfig` — 读 bundle 内 `desktop-public.env.json`，注入 web env
- `tryCloudBootstrap()` — 无 secrets 时走 cloud email bootstrap + Keychain
- `attachHostDirect()` — slim 模式用 Keychain host token Swift 原生 attach
- `QRCLAW_BUNDLE_MARKER=ai.qrclaw.desktop` 注入 gateway/web

### 构建

- `scripts/build-desktop-resources.sh --deliverable` — dev-full host attach + 嵌入 public Supabase keys
- `scripts/build-deliverable-dmg.sh` — 一键 resources → .app → DMG → static verify
- `script/build_and_run.sh build` — 只打包不 open

### 验证

- `tests/ecc-local-verify-macos-desktop.mjs` — 检查 `isDesktopBootstrap` 接线（非字面量 DESKTOP_AUTO_BOOTSTRAP）

## 测试基线

## 已知限制

- **Developer ID / notarize**：未配置 `CODESIGN_IDENTITY` / `NOTARY_*`，当前 ad-hoc DMG
- **C2-clean 无 secrets.env**：需 cloud bootstrap API 在 `gateway-test.qrclaw.ai` 可用；本机有 `~/.config/qrclaw/secrets.env` 时走 dev-full 全链路
- **ensure-daemon** 在 desktop 模式仅 probe，host 由 Orchestrator 启动（不 spawn qrclaw-setup.sh）
