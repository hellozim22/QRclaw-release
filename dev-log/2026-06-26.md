## Decisions
- Progress remains local-only for this workflow; no Supabase tables or remote persistence.
- Local agents manage tasks through `qrclaw-agent-host progress` and a shared local API/file store.
- The 50% context mechanism starts as a local summarizer MVP and can later be upgraded to a hidden local provider run.
- For `pi` on DeepSeek V4 Flash, the adapter still defaults to non-thinking mode only when no explicit thinking level is set. Current local user config explicitly enables `QRCLAW_PI_THINKING=high`, and the latest smoke returned `OK`.
